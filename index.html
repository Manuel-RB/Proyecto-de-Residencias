Requisitos de Microsoft Office 365
Sistema operativo
Windows OS: Windows 10, Windows 8.1, Windows Server 2019, Windows Server 2016.
macOS: Una de las tres versiones más recientes de macOS. Cuando se publica una nueva versión principal de macOS, la versión de macOS y las dos anteriores.
Equipo y Procesador
Windows OS: 1.6 GHz o más rápido, dos núcleos.
macOS: Procesador Intel.
Memoria RAM
Windows OS: 4 GB de RAM; 2 GB de RAM (32 bits).
macOS: 4 GB de RAM.
Disco duro
Windows OS: 4 GB de espacio disponible en disco. macOS: 10 GB de espacio en disco disponible. Disco duro con formato HFS+ (también conocido como Mac OS Extended).
